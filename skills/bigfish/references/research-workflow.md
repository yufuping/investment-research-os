# 研究路由与证据工作流

## 1. 选择研究深度

### 直接回答

适用于概念解释、已有研究内容讨论和不需要大量新证据的问题。回答应直接、可核验，并指出关键限制。

### 财务数字与计算

先从监管申报或公司官方资料获取原始数字，再使用确定性工具计算。不得让语言模型凭记忆完成复杂算术。

### 估值

只核验估值必要输入并运行反向估值、期末市盈率、股息和情景计算。除非用户要求，不扩展成完整研报。

### 聚焦研究

围绕一个决定性问题建立小型研究树，例如竞争产品是否正在削弱护城河、资本开支是否产生合理回报。

### 完整研究

适用于首次覆盖、完整更新或明确要求判断是否值得投资。至少包含动态研究树、公司质量、五年经营趋势、核心风险、反方验证、估值、情景、关键未知和持续跟踪。

### 重大投资决策

在完整研究基础上增加更严格的反方验证和组合相关性思考。只有用户明确确认实际行为后，才保存交易或正式决策。

## 2. 动态研究树

不要从“收入、利润、市盈率、风险”固定清单出发。先识别：

1. 主要利润池；
2. 终端需求变量；
3. 长期份额与护城河变量；
4. 单位经济性或利润率变量；
5. 资本强度与现金转化变量；
6. 当前价格隐含的关键假设。

围绕这些变量提出能够改变结论的问题。按“潜在影响 × 当前不确定性”排序，优先调查高影响且低置信度的节点。研究树应随证据调整，已经解决的低影响问题不应继续消耗研究预算。

## 3. 证据等级与标签

默认证据优先级：

1. SEC、HKEX及其他监管申报；
2. 公司财务报表和投资者关系披露；
3. 公司业绩电话会；
4. 监管机构或交易所资料；
5. 高质量新闻媒体；
6. 可靠第三方数据库；
7. 行业材料；
8. 论坛和社交媒体。

重要陈述使用以下标签：

- **事实：**有可靠来源直接支持；
- **管理层说法：**公司或管理层的陈述，尚不等于外部验证事实；
- **估算：**基于公开输入计算或推导；
- **假设：**估值或情景所需、尚未验证的前提；
- **观点：**对事实、估算和假设的解释判断。

材料冲突时说明冲突，不要偷偷选择更符合原论点的数据。重大估值输入优先使用一手来源，并保留来源日期、期间和定义。

## 4. 关键未知

高影响但证据不足的问题应形成正式输出：

```text
关键未知：
影响：低 / 中 / 高 / 极高
现有证据：
置信度：低 / 中 / 高
下一步：继续检索 / 寻找客户证据 / 转入情景分析 / 暂时搁置
```

如果继续搜索的成本明显高于可能改善的决策质量，可以保留未知并使用更保守的情景，不需要假装问题已经解决。

## 5. 反方验证

最终判断之前：

1. 用一句话写出核心投资论点；
2. 找出使它成立的三至五个关键假设；
3. 对每个高影响假设寻找反证；
4. 说明什么证据会真正推翻论点；
5. 检查估值是否已经假设所有关键变量都成功；
6. 给出“最可能错在哪里”的排序结论。

反方验证的目标不是悲观，而是减少确认偏误。

## 6. 研究预算

研究深度与决策重要性匹配。简单问题不启动完整研究；高仓位或高不可逆性的实际投资决策需要更强证据、反方验证和压力测试。停止条件是已经获得足以支持当前决策的证据，而不是穷尽互联网。
